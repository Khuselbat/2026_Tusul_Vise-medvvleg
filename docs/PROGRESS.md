## Үе 6 — 2026-11-18

### 1. Имэйл баталгаажуулалт ба нууц үг сэргээх
**Шалтгаан:** `.env` файл байгаагүй тул сервер хөгжүүлэлтийн анхдагч `MAIL_TRANSPORT=file` горимд ажиллаж, захидал
`server/mail-outbox/`-д хадгалагдаж байв (2026-11-18 07:03, 07:04-ийн хоёр “Дахин илгээх” тэнд байсан; холбоос нь зөв
`http://localhost:5173/verify-email` руу заасан). SMTP огт тохируулагдаагүй, илгээлтийн алдааг хэрэглэгчид харуулдаггүй байв.

Хийсэн:
- `SMTP_HOST, SMTP_PORT, SMTP_SECURE, SMTP_USER, SMTP_PASS, MAIL_FROM, APP_BASE_URL` (хуучин `SMTP_PASSWORD`, `APP_URL` хэвээр);
  `SMTP_HOST` тохируулбал автоматаар SMTP; 465 портод TLS. Gmail App Password-ийн заавар — `.env.example`, `WINDOWS_SETUP.md`.
- SMTP-гүй dev: холбоос терминалд тод хүрээтэй; `MAIL_TRANSPORT=ethereal`; Docker `--profile mail` (Mailpit).
- Сервер эхлэхэд имэйлийн горимыг хэлнэ; SMTP_HOST-гүй smtp бол алдаа.
- Алдааг кодоор ангилж (`MAIL_AUTH`, `MAIL_CONNECTION`, `MAIL_REJECTED`, `MAIL_NOT_CONFIGURED`) монгол мессежтэй; “Дахин илгээх” 502-оор
  харуулна, бүртгэлийн үед `mailSent=false` → нэвтрэх хуудсанд анхааруулга.
- “Дахин илгээх”: 60 сек (сервер + UI тоолуур). Токен: баталгаажуулалт 24 цаг, нууц үг 1 цаг, нэг удаагийн, хэшлэсэн.
- Нууц үг сэргээх: байгаа/байхгүй имэйлд ижил хариу; SMTP эвдэрсэн бол бүгдэд ижил 503.
- Админы самбар → “Имэйл (SMTP)” карт: тохиргооны тойм (нууц үггүй), **“Туршилтын имэйл илгээх”** (өөрийн хаяг руу).
