# ЦАХИМ ВИЗ · E-VISA — брэнд ба дизайны систем

Лавлагаа: `mockup-home.png`, `mockup-hero.png`, `mockup-home.html` (чиглэл — пикселийн нарийн тодорхойлолт биш).
Код: токен — `client/src/styles.css` (эхний хэсэг), лого — `client/src/components/Brand.jsx`, икон — `client/public/`.

## 1. Нэр

| Түвшин | Бичлэг | Хэрэглээ |
| --- | --- | --- |
| Үндсэн | **ЦАХИМ ВИЗ** | Лого, гарчиг, монгол текст |
| Хоёрдогч | **E-VISA** | Логоны дэд бичвэр, англи хэлний орчин |

Брэндийн нэрийг орчуулахгүй (англи горимд ч “ЦАХИМ ВИЗ / E-VISA”). Төрийн сүлд, туг, агаарын тээврийн компанийн
лого, гуравдагч брэндийн тэмдэг, бодит хүний зураг **ашиглахгүй** (mockup дахь БНСУ-ын тугийг ISO “KR” тэмдгээр сольсон).

## 2. Лого

Тэмдэг: **паспортын хүрээ + бөмбөрцөг + баталгаажуулах тэмдэг**, `#2D9BFF → #1FD0E5` gradient дөрвөлжин (rx 13/48).

| Хувилбар | Код | Хэзээ |
| --- | --- | --- |
| Хэвтээ | `<Logo layout="horizontal" />` | Header, footer (тэмдэг + ЦАХИМ ВИЗ / E-VISA) |
| Нягт | `<Logo layout="compact" />` | Нарийн зай (тэмдэг + ЦАХИМ ВИЗ) |
| Зөвхөн тэмдэг | `<LogoMark />`, `favicon.svg` | Икон, ≤480px header (нэр нь дэлгэц уншигчид үлдэнэ, D-80) |
| Бараан дэвсгэр дээр | `tone="on-dark"` | Нэр `#F5F9FF`, E-VISA `#20D4E8` |
| Цайвар дэвсгэр дээр | `tone="on-light"` | Нэр `#0B1B33`, E-VISA `#07707F` |
| Нэг өнгө | `tone="mono"` | Хэвлэл, тамга — `currentColor`, дэвсгэргүй хүрээ |

- **Хамгийн бага хэмжээ:** тэмдэг 16px (24px-ээс бага үед автоматаар хялбаршуулсан хувилбар — бөмбөрцгийн шугамгүй,
  зураас зузаан); хэвтээ лого 120px өргөн.
- **Чөлөөт зай:** тэмдгийн өндрийн ¼ (40px тэмдэгт 10px) — эргэн тойронд текст, хүрээ оруулахгүй.
- **Икон:** `favicon.svg` (16px-д уншигдана), `icon-32.png`, `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`
  (maskable — дэвсгэр бүтэн, тэмдэг аюулгүй бүсэд), `site.webmanifest`.

**Хийж болохгүй:** тэмдгийг сунгах/эргүүлэх, gradient-ийг өөр өнгөөр солих, сүүдэр/гэрэлтэлт нэмэх, тэмдгийн дотор
текст бичих, бараан дэвсгэр дээр `on-light` хувилбар ашиглах, 16px-ээс жижиг харуулах.

## 3. Өнгө

Dark горим **анхдагч** (D-90); light нь ижил шатлалтай. Бүрэлдэхүүнүүд семантик токен (`--card`, `--ink`, `--primary`…)
ашиглана — брэнд hex-ийг шууд бичихгүй. Текстийн токен бүрийг 5 дэвсгэр (хуудас, bg-2, гадаргуу, талбар, hover) дээр
тооцоолж **WCAG AA ≥4.5:1** гэдгийг шалгасан.

| Токен | Dark | Light | Хэрэглээ |
| --- | --- | --- | --- |
| `--bg` / `--bg-2` | `#06162E` / `#0B2344` | `#F3F7FC` / `#E8EFF8` | Хуудас, хоёрдогч дэвсгэр |
| `--surface` (`--card`) / `--surface-2` (`--hover`) | `#0F2A4C` / `#163A62` | `#FFFFFF` / `#EAF1F9` | Карт, hover |
| `--text` (`--ink`) / `--text-2` (`--ink-2`) | `#F5F9FF` / `#A9BED5` | `#0B1B33` / `#33496A` | Текст |
| `--muted` | `#93AAC5` ¹ | `#53698A` | Туслах текст |
| `--border` (`--line`) | `#1F4063` | `#D5E1EE` | Хүрээ (нарийн) |
| `--primary` | `#5AAFFF` ² | `#0B63C4` | Холбоос, идэвхтэй/сонгосон төлөв |

**Дүрэм:** цэнхэр/цэнхэр-ногоон зөвхөн үндсэн үйлдэл, идэвхтэй, сонгосон төлөвт. Градиент, гэрэлтэлт зөвхөн Hero ба
“Визийн хариу шалгах”-д. Дэвсгэр 2 түвшин (хуудас, карт).

## 4. Үсэг

**Inter** (variable, `@fontsource-variable/inter` — өөр дээрээ, CSP-д нийцнэ; `cyrillic-ext` нь Ө, Ү-г агуулна).

| Токен | Хэмжээ (clamp) | Хэрэглээ |
| --- | --- | --- |
| `--fs-display` | 40 → 76px | Hero гарчиг |
| `--fs-h1` | 32 → 56px | Хуудасны гарчиг |
| `--fs-h2` | 26 → 42px | Хэсгийн гарчиг |
| `--fs-h3` | 17 → 20px | Карт, дэд гарчиг, lead |
| `--fs-body` | 15 → 17px | Үндсэн текст (мөрийн өндөр 1.6, ≤70ch) |
| `--fs-small` | 13 → 14px | Шошго, тайлбар, badge |

## 5. Зай, радиус, сүүдэр, фокус

- Зай: `--sp-1…10` = 4/8/12/16/24/32/48/64/96/128px; хэсэг хоорондын зай `--section` = `clamp(64px, 8vw, 120px)`.
- Радиус: `--radius-sm` 10 · `--radius` 16 · `--radius-lg` 24.
- Сүүдэр: `--shadow` · `--shadow-md` · `--shadow-lg` (3 түвшин).
- Фокус: нэг хэв маяг — `:focus-visible` 3px `--focus` (dark `#20D4E8`, light `#0B8FB0`) хүрээ, 2px зай.
- Хөдөлгөөн: ≤400ms, ease-out, үсрэлтгүй; `prefers-reduced-motion`-д хөдөлгөөнгүй; opacity-гүй (D-78).

## 6. Текстийн үнэн байдал (заавал)

- Байхгүй зүйлийг бүү мэдэгд: “24/7 дэмжлэг”, “Дэлхийн олон улс”, “албан ёсны үйлчилгээ”, зохиомол утас/имэйл,
  хураамж, шийдвэрлэх хугацаа, “бүртгүүлэхэд 1 минут” г.м.
- Мэдүүлэг зөвхөн **БНСУ**; бусад улс “Тун удахгүй”. Зөвхөн **нийтэлсэн** визийн ангилал; ноорог нь
  “+N ангилал баталгаажиж байна”.
- Систем **бүрдлийг** шалгана, визийн шийдвэр гаргахгүй (BR-09). Төлөвийн нэр: Ноорог · Илгээсэн · Бүрдэл хянаж байна ·
  Нэмэлт материал шаардсан · Бүрдэл бүрэн · Эрх бүхий байгууллагад хүргүүлсэн. “Зөвшөөрсөн/Татгалзсан” зөвхөн
  мэдүүлэгчийн өөрөө бүртгэсэн албан үр дүн гэж тодорхой тэмдэглэгдэнэ.
- Зочинд “дугаар оруулаад төлөв харах” хуудас байхгүй (нууцлал / IDOR) — явц зөвхөн нэвтэрсний дараа.
