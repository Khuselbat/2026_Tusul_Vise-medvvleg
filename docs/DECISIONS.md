# Шийдвэрийн бүртгэл

Тайлантай зөрчилдсөн, тодорхойгүй эсвэл таамагласан шийдвэрүүд. Төлөв: **НЭЭЛТТЭЙ** (эзэмшигчийн хариу хүлээж буй) · **ШИЙДСЭН**.

## Шийдсэн (MVP-ээс өвлөсөн)

| # | Шийдвэр | Үндэслэл |
|---|---|---|
| D-01 | Анкетын ноорог серверт шифрлэн хадгалагдана (Зураг 43-т “зөвхөн санах ойд” гэсэн) | F04 “хадгалаад үргэлжлүүлнэ”; цуцлахад ноорог + түр файл бүрэн устна (UC-04 A3) |
| D-02 | Оператор паспортын дугаарыг нууцлагдсан хэлбэрээр харна | Зураг 52; хавсаргасан хуулбартай тулгана |
| D-03 | Нүүр хуудсын 3 улс “Улс 2/3/4 · Тун удахгүй” placeholder, DB-д оруулахгүй | Зураг 55: баталгаажаагүй нэрийг seed-д оруулахгүй |
| D-04 | UC-07 E2 (файл нээгдэхгүй бол дүгнэлт батлахгүй)-ийг сервер шалгах боломжгүй — UI түвшинд хэрэгжүүлнэ | Оператор файлыг нээсэн эсэхийг сервер найдвартай мэдэхгүй |

## Нээлттэй — эзэмшигчээс асуух

Дэлгэрэнгүйг `GAP_ANALYSIS.md` §10-аас үзнэ үү.

| # | Асуулт | Санал болгосон хувилбар |
|---|---|---|
| Q1 | Албан үр дүнг хэн бүртгэх: тайлан 5.3 (оператор) ↔ prompt (мэдүүлэгч; оператор/админ засахгүй) | Мэдүүлэгч бүртгэнэ (append-only); оператор зөвхөн тусдаа “тулгасан” тэмдэглэл нэмнэ |
| Q2 | F11-ийн “зөвшөөрсөн/татгалзсан” ↔ CLAUDE.md дүрэм 5 | Мэдүүлэгчийн өөрөө оруулсан порталын үр дүн гэж шошголж зөвшөөрнө |
| Q3 | “Хүргүүлсэн”-ийг хэн, ямар төлвөөс бүртгэх | Хуваарилагдсан оператор, зөвхөн COMPLETE-ээс; албан дугаар + огноо + нотолгоо заавал |
| Q4 | 5.2-ын лавлахын нэмэлт талбаруудыг нэмэх эсэх | Migration-оор nullable багана |
